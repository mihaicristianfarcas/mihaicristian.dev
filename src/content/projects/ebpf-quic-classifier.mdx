You can't read encrypted traffic, but it still has a shape: a video call looks
nothing like a file download. This captures QUIC packets inside the kernel with
eBPF, records the sizes, directions, and timing of each flow, and hands them to
a small neural network that names one of 102 applications. It gets 88% of
flows it has never seen right, in about 5.5 ms each, light enough to run on a
Raspberry Pi 5 at the edge.
