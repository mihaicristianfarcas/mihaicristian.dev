Search and replace across a project never had tooling I fully trusted: read a
quickfix list like a compiler dump, or fire a `sed` command blind and hope. This
one shows a before and after for every match while results are still streaming
in, lets you pick the ones you want, and keeps an undo history that survives a
restart. Before it writes, it checks each match is still there, so a stale
result can't corrupt a file.

I built it because I wanted it, and I use it every day. Other people found it
and use it too.
