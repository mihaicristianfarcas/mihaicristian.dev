My own go at "chat with an AI, get an app". An agent writes a working Next.js
app, you watch it run in a live preview, and you keep talking to change it.
Generation turned out to be the easy half. Running code an AI has just written
is a real security problem, so every project gets its own isolated cloud
sandbox, and nothing it writes ever touches the host.
