Vibe is my own go at the "chat with an AI, get an app" idea. You describe what
you want, an agent writes a working Next.js application, and you watch it run
in a live preview beside the conversation. Keep talking and it keeps editing.

Generation turned out to be the easy half. Running code an AI has just written
is a genuine security problem, so every project gets its own isolated cloud
sandbox and nothing generated ever touches the host. That constraint ended up
shaping the whole architecture.

## How it works

Each sandbox boots from a template I built: a Next.js app with every shadcn/ui
component already installed, so the agent spends its time on the product and
not on setup. The agent itself has exactly three tools: a terminal, and reading
and writing files. It installs what it needs, writes the pages, and when it's done
it hands back a short summary of what it built.

The whole run happens as a background job, so a long generation isn't tied to
an open request, and the app just waits for the result. That result is saved
as a fragment: the files, a title, and the address of the sandbox it's running
in. The live preview and the code view both read from it, and every answer
keeps its own fragment, so you can click back to any earlier version and see
exactly what it built.

Around that sits an ordinary product: sign-in, a list of projects, and a
conversation history per project, all typed end to end.

Nobody paid me for this one. It was the most fun I'd had with an uncomfortable
engineering problem in a while.
