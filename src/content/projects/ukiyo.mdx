*Ukiyo*, the floating world. A modal terminal text editor written in Rust,
built to answer a question I'd been carrying around for years: what's actually
in there?

I'd used editors every day for years without once thinking about the machinery.
How does a buffer really work? What is a mode, mechanically? Why is undo so much
harder than it looks? The only way I know to stop wondering about something is
to build it, so I did: modes, a file explorer, visual line wrapping, and a
command-based undo system. Every one of those I understood properly only after
implementing it.

## What's inside

It's also where I got to use the classic design patterns somewhere they
genuinely fit, instead of where a textbook wanted them, and each one earns its
place.

Modes are the State pattern. Normal, insert, command, and explorer are each
their own type that reads a key and hands back an action, so the editor never
asks which mode it's in, and adding a mode doesn't touch the others. Every edit
is a Command that knows how to undo itself, which, it turns out, is all undo
and redo really are: two stacks of those. The status bar and the editor view
observe the buffer rather than being told when to redraw, so the text itself
knows nothing about the screen. The file explorer is a Composite, a tree where a
directory and a file answer to the same interface.

None of that is how I'd have written it before. That taught me more than the
editor did.
